# Feature: 기준별 티어 설명 (tier-rubric)

**단계**: 정적 웹 · **선행**: M1

## 문제
S/A/B/C가 기준마다 무엇을 뜻하는지 적어둘 곳이 없어서, 평가 중에 기억에 의존하게 되고 대상자 간 판단이 흔들린다.

## 목표 / 비목표
- 목표: 기준마다 S/A/B/C 설명을 작성하고 평가 중에 바로 확인.
- 비목표: 설명에 따른 점수 변화, 서식 있는 텍스트(굵게 등), 설명 공유/내보내기 별도 기능 (JSON 내보내기에는 포함).

## 요구사항
- 설정 페이지: 기준마다 S/A/B/C 설명 입력.
- 평가 페이지: 현재 기준의 설명을 화면 이동 없이 확인 (접이식 패널, 필요 시 티어 라벨 옆 툴팁).
- 설명이 없는 기준은 M1과 똑같이 동작한다.
- 점수·순위 규칙은 M1과 동일.
- JSON 내보내기/가져오기에 설명이 포함된다.

## 완료 기준
- 5개 기준에 설명을 작성하고, 평가 중 다른 화면 이동 없이 설명을 확인할 수 있다.
- M1에서 저장하거나 내보낸 데이터가 그대로 열린다.
- 평가자가 "기억에 의존했던" 순간이 줄었는지 직접 확인한다.

## 기술 방식
- 데이터: `criteria[].rubric = { S, A, B, C }` 추가. 필드가 없으면 빈 설명으로 처리하므로 `version` 증가 없음.
- 설정 화면: 기준마다 텍스트 입력 4칸.
- 평가 화면: `<details>` 접이식 패널 (브라우저 기본 기능, 스크립트 불필요).
- JSON 가져오기 검증에 `rubric` 형식 검사 추가 (문자열 4개, 없으면 허용).

## 테스트
- `rubric` 필드가 없는 M1 데이터가 오류 없이 열린다.
- 설명이 있는 데이터가 내보내기 → 가져오기 후에도 유지된다.

## 기획자 판단 / 열린 질문
- 설명은 일반 텍스트(줄바꿈만 허용)로 한다.
- 설명 패널은 기본 접힘 상태로 둔다 (길면 평가 화면이 밀림).
